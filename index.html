01 / THE TRAPS

The five that cost the most.

Each of these shipped to real users before it was found. All 21 are in the kit, grouped by where they bite: models, deploy, verification, environment.

Models

Your proxy silently strips images

The request returns 200. The model answers "I can't see an image." Nothing errors — the image part was dropped before it ever reached the model.

Fix: route vision to a verified endpoint; prove it with a random 6-digit number.
Deploy

The gateway kills long requests at a hidden wall

Works locally. Dies at ~15s in production. Your server logs never show the request finishing, because the connection was cut upstream.

Fix: accept in <2s, run the work server-side, poll a task state machine.
Judgment

You tested A and shipped B

A file named "bilingual subtitles" passed every check except the one that mattered: it had no subtitle track at all.

Fix: open the deliverable itself, through the path the user takes.
Judgment

A check that never saw a failure

A detector reported "outline too heavy" and blocked a good render. It was measuring background brightness — a 3.6× swing for identical settings.

Fix: one known-good and one known-bad input, every time.
Environment

Windows Python crashes on any Chinese print

The console codepage isn't UTF-8, so print() dies with UnicodeEncodeError — in a script that was fine yesterday.

Fix: force UTF-8 in the launcher, not in each script.
Deploy

A hung process never restarts

A deadlock doesn't exit. The service reports "active (running)" and silently stops doing work. Nothing pages you.

Fix: watchdog heartbeat. No heartbeat, systemd kills and restarts.
